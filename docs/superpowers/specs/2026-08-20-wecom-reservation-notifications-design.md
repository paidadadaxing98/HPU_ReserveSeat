# 企业微信预约结果通知设计

**目标**：在本地预约服务完成每个学习时段的预约尝试后，通过企业微信机器人把结果发送到手机。

## 范围

- 使用企业微信群机器人 Webhook，地址只从 `.env` 的 `SEAT_WECOM_WEBHOOK` 读取。
- 成功、明确失败、结果不明确三类预约结果都发送文本通知。
- 成功消息包含日期、学习时段、预约时间、阅览室、座位和签到提醒。
- 失败消息包含日期、学习时段、状态和原因。
- 通知发送异常不改变预约结果，也不触发重复预约。
- 暂不购买云资源，不实现企业微信小程序回调或公网中继。

## 数据流

```text
AssistantService.reserve_period
    -> 保存预约结果
    -> NotificationSink.send
    -> WeComNotifier POST /cgi-bin/webhook/send
```

通知器使用可注入接口，测试中使用内存通知器；未配置 Webhook 时保持静默，不影响现有 dry-run 和本地控制流程。

## 验收标准

1. 配置 `SEAT_WECOM_WEBHOOK` 后，预约成功会发送一条可读文本。
2. 预约失败或适配器异常会发送对应失败/不明确结果。
3. Webhook 未配置或发送失败时，预约方法仍返回原预约结果。
4. 所有现有测试和新增通知测试通过。
